# Hi, I'm sho9029 👋

I'm a master's student researching machine learning, with a particular interest in abstraction, representation learning, and object understanding.

My research broadly explores how learning systems can capture meaningful structure in data and use it for generalization beyond surface-level patterns. I am interested in both the theoretical questions behind machine intelligence and the practical process of building and evaluating learning systems.

Alongside my research, I develop software for machine learning experiments, Windows applications, media processing, and workflow automation.

## Research Interests

- **Abstraction and Representation Learning**  
  Understanding how machine learning systems can capture useful structure in data and acquire representations that generalize across different situations.

- **Object Understanding**  
  Exploring how models can represent and distinguish objects using structure, context, and relationships rather than relying only on observable features.

- **Generalization and Robustness**  
  Studying learning systems that behave consistently beyond the specific data and conditions encountered during training.

- **Conceptual Modeling**  
  Investigating computational perspectives on concepts and structured understanding, including connections between machine learning and cognitive science.
